# Personal v4 Mobile App

Hi Future Developer,

Welcome to the **Personal v4 Mobile App**! This project is an open-source mobile application companion built with the latest **Expo SDK 57**, **React 19**, and **React Native 0.86**, designed for intuitive personal utility, finance management, and on-the-go productivity.

This repository is the frontend mobile client of our ecosystem, created to accompany the **Personal Filament Admin Panel**. It offers a fast, fluid, and responsive mobile experience across Android, iOS, and the web, connecting seamlessly with our Laravel backend API.

> **Note:** This mobile app is the companion client of the [Personal Filament Admin Panel](https://github.com/novaardiansyah/personal-v4), powered by Laravel Sanctum authentication with persistent 7-day token sessions.

## Dazzling Tech Stack

- [Expo SDK 57](https://docs.expo.dev/) - Universal Native Mobile Framework
- [React 19](https://react.dev/) & [React Native 0.86](https://reactnative.dev/) - Mobile Runtime & UI Components
- [Expo Router v57](https://docs.expo.dev/router/introduction/) - Typed File-based Routing
- [TypeScript](https://www.typescriptlang.org/) - Static Type Safety
- [NativeWind v5](https://www.nativewind.dev/) & [Tailwind CSS v4](https://tailwindcss.com/) - Utility-first Styling
- [Gluestack UI Core](https://gluestack.io/) - Accessible UI Primitives
- [React Native Reanimated v4](https://docs.swmansion.com/react-native-reanimated/) - Fluid Animations & Worklets
- [Async Storage](https://react-native-async-storage.github.io/async-storage/) - Local Persistent Session Storage

## Key Capabilities

- **Seamless Authentication**:
  - Secure login, registration, and password management.
  - Persistent 7-day session storage for smooth day-to-day access without repeated logins.
  - Automatic token verification with backend revocation on logout.

- **Financial & Utility Overview**:
  - Main balance dashboard with privacy visibility toggles.
  - Income and expense breakdown with localized currency formatting.
  - Quick banking & utility action shortcuts.
  - Real-time recent transaction tracking.

- **Profile & Personalization**:
  - Integrated profile management with instant API synchronization.
  - Native photo picker supporting both camera capture and photo gallery selection.
  - Account security settings and preferences.

- **Modern Design & User Experience**:
  - Custom curated brand color palette for high aesthetic standards.
  - Universal design optimized for Android, iOS, and Web viewports.
  - Modular, accessible, and high-performance component architecture.
